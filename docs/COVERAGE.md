# Control coverage by component

Companion to [THREAT_MODEL.md](THREAT_MODEL.md): which controls protect each component, and the test that exercises them. Letters are the STRIDE
classes the row addresses (Spoofing, Tampering, Repudiation, Information disclosure, Denial of service,
Elevation of privilege). *Phase B* tests are the deterministic, compromised-agent cases in the report;
other names are suites in `tests/suites/`.

| Component | Controls | Tests |
|---|---|---|
| `sbxctl` and user identity | API bound to localhost; owner checks on every session op; `system:*` reserved; output sanitised (`safe()`); contained-session release and destroy are admin-only. *Spoofing, Tampering, Repudiation, Elevation* | lifecycle; Phase B reserved identities; `safe()` and admin-only release by code review |
| Control plane API | Per-component key scopes (gateway key cannot reach GitHub routes); test-only session endpoint removed; declared parameters only; compare-and-set state transitions; per-pod resource limits. *Spoofing, Tampering, Repudiation, DoS, Elevation* | containment; Phase B trigger cannot widen policy, no session back door; caps by code review |
| Spec registry and baseline | Strict schema; org baseline (gVisor, exact hosts, approved models, bounded TTL and bursts, read-only repos); two-person digest approval, approver ≠ author; immutable versions; widening needs re-approval; bad-spec fixtures rejected. *Spoofing, Tampering, Repudiation, Elevation* | specs; Phase B unsafe specs rejected, non-gVisor pod refused |
| Workspace delivery and messages | Repo cloned and canary planted by the control plane (`O_NOFOLLOW`, 0600); files streamed in via exec args, never credentials; messages owner-only, ≤4000 chars, written atomically; running sessions only; agent-instruction files (`CLAUDE.md`, `AGENTS.md`, `.claude/`) withheld from the agent and restored for the diff. *Tampering, Repudiation, Disclosure, Elevation* | lifecycle, e2e; Phase B `CLAUDE.md` withheld; no-follow canary write by code review |
| State store and reconciler | Durable SQLite under a lock; pod loss ends the session and revokes its token; idle and lifetime reaper; contained retention; orphan sweep. *Tampering, Repudiation, DoS* | lifecycle |
| Kubernetes driver and admission | Namespace-scoped RBAC for the controller; ValidatingAdmissionPolicy refuses non-gVisor pods, SA tokens, missing session label, wrong node pool, hostPath/Secret/projected volumes. *Spoofing, Tampering, Elevation* | specs; Phase B gVisor runtime, non-gVisor pod refused, sandbox and credproxy on different nodes |
| Sandbox pod and agent runtime | gVisor; non-root, read-only root fs, all capabilities dropped, seccomp; sized emptyDirs; CPU/memory/TTL limits; no SA token; `--setting-sources user --strict-mcp-config`; a system prompt that marks repository content as data; spec models pinned via env; allowedTools from the spec. *Tampering, Repudiation, Disclosure, DoS, Elevation* | Phase B no credentials in the sandbox, gVisor runtime; Phase C runs with the settings lock |
| AI gateway | Placeholder token bound to pod IP and spec; client credentials stripped; Messages endpoints only, custom tools only, no server tools/MCP/URL sources; model allowlist and budget; per-IP in-flight cap; streaming tool_use inspection; bodies retained with canary redaction. *all six* | e2e; Phase B foreign key not forwarded, stolen token useless, provider-side tools / other endpoints / URL sources rejected |
| Egress proxy | Exact-host allowlist; write-capable hosts read-only unless the spec write-allows; CONNECT counts as a write; canary scan on plain HTTP; header, body and response caps; per-IP connection cap. *all six* | containment; Phase B direct TCP, non-allowlisted host, DNS, HTTP and TLS writes blocked, read-URL canary contained |
| Credentials proxy | Only holder of the inference key and GitHub App key; per-grant re-check against session policy with uncached lookups for GitHub; `Accept-Encoding: identity` so the gateway can inspect; repo-scoped per-operation tokens, revoked after use; FQDN egress allowlist; separate node from sandboxes. *all six* | github; Phase B credproxy unreachable from the sandbox, on a different node |
| Evidence log and shipper | Hash-chained JSONL with sequence numbers; shipped to the sentinel, which verifies chain and continuity on arrival and keeps its own copy; snapshots and transcripts taken at containment. *Spoofing, Tampering, Repudiation, Disclosure, DoS* | sentinel (`evidence-tampering`), e2e chain checks |
| Sentinel | Own namespace and node; SA limited to Cilium policies and pod list; ingest from the gateway pod only; rules fed by shipped evidence *and* Hubble; gateway-underreporting reconciles kernel request counts with gateway claims; telemetry-feed-silent alerts when its own feeds go quiet; containment memory survives restart; own deny policies protected by admission; containment verified by Hubble; detection policy validated against a compiled floor, rejected policies raise policy-rejected and keep the last good one. *all six* | sentinel, sentinel-completeness, sentinel-policy |
| Network fabric and nodes | Cilium default-deny in `sbx-sessions`; sandboxes reach only gateway :8080/:3128 while `running`; no DNS from sandboxes; Hubble L7 with credential redaction; three pools (sandbox tainted, platform, security). *Spoofing, Tampering, Disclosure, DoS, Elevation* | smoke; Phase B API server, credproxy and other sessions blocked, node separation |
| Lab services and samples | git-lab reachable only by the control plane (`git://`, read-only); sinks and paste-mock are in-cluster stand-ins so no real destination is ever targeted. *Spoofing, Tampering, Disclosure* | smoke; Phase B direct TCP, non-allowlisted host and DNS blocked |
| Build, deploy, supply chain | Pinned versions with sha256/sha512 checks for gVisor and Hubble; one services image; secrets only in gitignored `secrets/` and a pre-commit guard; `make dist` from `git archive`; fault injection off by default. *Spoofing, Tampering, Disclosure, DoS, Elevation* | smoke; open low-severity findings in [SECURITY_REVIEW.md](SECURITY_REVIEW.md) |
| GitHub integration | App with Contents and Pull requests only, no Workflows; draft PRs; diff recomputed by the control plane; protected paths refused; canary in diff or body refused with canary-exfiltration; summary quoted inert. *all six* | github (incl. regressions for the diff-forgery and PR-body findings) |

**Not covered or thin:** hardware-level isolation (gVisor, not a microVM), user identity (header), TLS
payload inspection for write-allowed hosts, detection beyond the canary (real secrets, slow or split
exfiltration), and the open lows in the review (shared port 8000, image rules at admission, budget
atomicity, supply-chain digests).
